# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- GitHub Actions workflows for CI/CD
- Automated changelog generation
- Version validation scripts
- ESLint configuration for code quality
- Bundle size tracking

### Changed
- Updated manifest with author information
- Improved base file integration with Obsidian Bases plugin

### Fixed
- Base file format now uses proper Obsidian Bases YAML structure
- Added missing status field to note frontmatter

## [0.1.0] - 2024-11-05

### Added
- Initial release of Daily Link Clipper
- Automatic link extraction from daily notes
- AI-powered classification via OpenRouter API
- Heuristic-based classification fallback
- Metadata extraction from web pages
- Integration with Obsidian Bases plugin
- Configurable wishlist and reading list bases
- Debounced file modification processing
- Commands for manual processing
- Settings tab for configuration
